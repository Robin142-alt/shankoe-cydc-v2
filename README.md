# Shankoe CYDC — Official Web Platform

> **Empowering Children & Young People to Thrive**  
> Methodist Child & Youth Development Centre • Narok County, Kenya

---

## 📖 Overview

**Shankoe CYDC** operates directly within the Shankoe community in Narok County, Kenya, supported by the Methodist Church in Kenya and global child development partners. This web platform is designed around the core narrative of **"BECOMING"** — walking visitors through the transformative journey:

$$\text{EMBRACE} \longrightarrow \text{ENGAGE} \longrightarrow \text{EMPOWER} \longrightarrow \text{THRIVE}$$

---

## ✨ Features & Architecture

- **Cinematic Homepage**: Includes a brand hero, "Who We Are", the Embrace/Engage/Empower journey cards, program pillars, live-animated impact counter strip, filterable Life at Shankoe gallery, and the official Vision & Mission declaration.
- **Dedicated Pages**:
  - **About Our Mission** (`#about`): Community history, Methodist identity, official Vision & Mission, and 6 core organizational values.
  - **Holistic Programs** (`#programs`): Deep dive into Education, Practical Vocational Skills (featuring authentic baking & culinary training), Wellbeing & Nutrition, Child Protection, and Climate Resilience.
  - **Theory of Change & Impact** (`#impact`): Structured transformation framework and accountability spotlights.
  - **Stories of Growth** (`#stories`): Editorial stories documenting daily life and milestones.
  - **News & Happenings** (`#news`): Updates on culinary exhibitions, health days, and community gatherings.
  - **Contact & Location** (`#contact`): Centre address, church grounds location, hours, and direct messaging form.
  - **Partner With Us** (`#partner`): Specialized collaboration tracks for vocational support, nutrition funding, educational sponsorships, and safe play amenities.
- **Interactive UI & Lightbox**: Click any authentic photograph across the site to open an interactive modal with photo metadata, descriptions, and category tags.
- **Micro-Animations & Polished UX**: Custom loading screen, scroll-triggered card reveals, smooth scrolling, and responsive drawer navigation.

---

## 🛠️ Tech Stack

- **Framework**: React 19 + Vite 7
- **Icons**: Lucide React
- **Typography**: Google Fonts (*Outfit* & *Plus Jakarta Sans*)
- **Styling**: Modern Vanilla CSS Design System with CSS variables and responsive breakpoints

## 🚀 Getting Started

### Prerequisites
- Node.js (v18+)
- npm or pnpm

### Installation
```bash
npm install
```

### Development Server
```bash
npm run dev
```

### Production Build
```bash
npm run build
```
